# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability within **OurHour**, please submit a private vulnerability report via GitHub Security Advisories or contact the maintainers directly.

All security vulnerabilities will be promptly assessed and addressed with the highest priority.
